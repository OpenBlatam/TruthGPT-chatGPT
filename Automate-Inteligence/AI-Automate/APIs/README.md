# 🧠 Code Open Source

## 👥 Human Agents  
**[HumanLayer](https://github.com/humanlayer/humanlayer)**  
Empower human-in-the-loop AI systems. Coordinate tasks between humans and agents with trust, feedback, and control built in.

---

## 🌐 Parse Web Pages  
**[Firecrawl](https://github.com/mendableai/firecrawl)**  
An open-source web scraping and crawling tool built for LLMs. Extract data from the web at scale with minimal setup.

---

## 📄 Parse Documents  
**[Chunkr](https://github.com/lumina-ai-inc/chunkr)**  
Smarter document chunking for LLMs. Prepares your data for optimal embedding and retrieval.

**[Zerox](https://github.com/getomni-ai/zerox)**  
AI-powered PDF and document parsing. Convert and structure complex documents for LLM pipelines.

---

## 🪙 Crypto & Trading  
**[Alpaca-Py](https://github.com/alpacahq/alpaca-py)**  
The official Python SDK for Alpaca's trading API. Access real-time market data and place trades programmatically.
