# Automate Intelligence

## Description

**Automate Intelligence** is the creation of workflow automation platforms designed to simplify and enhance productivity. Similar to make and n95, but with a focus on mobile UI for creative professionals. Initially launched in **Blatam** and open-source communities, this platform aims to empower users to design and execute automation workflows with ease, making complex processes accessible through a user-friendly interface.
