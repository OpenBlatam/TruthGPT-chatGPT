

## 🔬 Open Source Projects – Quantum Transformers

| Project Name             | Description                                                                 | Tech Stack           | GitHub Link                                                                 |
|--------------------------|-----------------------------------------------------------------------------|----------------------|-----------------------------------------------------------------------------|
| **Quantum-Transformer**  | Hybrid quantum-classical transformer with quantized self-attention for molecular generation. | CUDA-Q, RDKit, PyTorch | [🔗 GitHub](https://github.com/anthonysmaldone/Quantum-Transformer) |
| **QTransformer**         | GPT-2-like LLM with quantum circuits for attention mechanisms. | PyTorch, Qiskit      | [🔗 GitHub](https://github.com/TimStep/QTransformer) |
| **rdisipio/qtransformer**| Quantum-enhanced transformer neural network for classification tasks. | TensorFlow, PyTorch  | [🔗 GitHub](https://github.com/rdisipio/qtransformer) |
| **Quixer**               | Quantum transformer model utilizing Linear Combination of Unitaries and Quantum Singular Value Transform primitives. | PyTorch, Quixer      | [🔗 GitHub](https://github.com/Quixer/Quixer) |
| **transformer_quantum_state** | Multi-purpose model for quantum many-body problems, implementing the transformer quantum state. | PyTorch, TeNPy       | [🔗 GitHub](https://github.com/yuanhangzhang98/transformer_quantum_state) |
| **Quantum NLP Demo**     | PennyLane template for quantum NLP, extensible to transformer models. | PennyLane, PyTorch   | [🔗 GitHub](https://github.com/PennyLaneAI/qnlp-demo) |
| **Quantum Self-Attention Neural Networks** | Introduces quantum self-attention neural networks for text classification. | PyTorch, Qiskit      | [🔗 GitHub](https://github.com/GuangxiLi/Quantum-Self-Attention-Neural-Networks) |
| **Quantum Vision Transformers** | Applies quantum transformers to high-energy physics analysis at the Large Hadron Collider. | TensorFlow, PyTorch  | [🔗 GitHub](https://github.com/MarvelFyy/quantum-transformer) |
